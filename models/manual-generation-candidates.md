## 판단

`OpenVINO/Qwen2.5-1.5B-Instruct-int4-ov`의 고정 리비전 `748d8cc119574c982192d9473e77bcf68273dd5a`을 로컬 CPU 파일럿으로 선택합니다.

- OpenVINO 공식 변환본이며 OpenVINO IR과 INT4 대칭 압축을 이미 적용했습니다.
- 원 모델과 변환 모델은 Apache-2.0이고 모델 카드에 한국어가 지원 언어로 명시되어 있습니다.
- 원 모델은 지시 이행과 JSON 구조화 출력 개선을 명시하며, 현재 서버의 구조화 claim 계약과 맞습니다.
- 로컬 파일은 892.64MB로, 같은 계열 7B INT4 약 4.48GB나 1.5B FP16 약 3.11GB보다 현재 16GB 노트북의 파일럿에 적합합니다.

이 판단은 모델 가중치의 일반적인 정확도나 실제 차량 정비 안전성을 승인하는 결정이 아닙니다. 서버는 계속 모델 출력을 신뢰하지 않고 인용·수치·어휘 근거를 검증합니다.

## 실제 현대·제네시스 문서 탐색 결과

로컬에 준비된 넥쏘 2021 및 ELECTRIFIED GV70 2027 공식 문서 인덱스에서 검색 1위 원문만 생성 근거로 사용해 대표 질문 3개를 추가 측정했습니다. 원문 파일과 발췌문은 Git에 포함하지 않았습니다.

| 질문 | 결과 | 지연 |
| --- | --- | ---: |
| 핸들이 있는 부스트 버튼은 뭐야? | 통과 · 인용 `[1]` | 첫 호출 34.90초 |
| 스마트키 배터리 교체 | 차단 · 근거 어휘 검증 실패 | 9.33초 |
| 12V 배터리 방전 시동 방법 | 차단 · 근거 어휘 검증 실패 | 8.12초 |

부스트 답변은 “차량을 가속할 때 모터 오버부스트가 작동하는 모드”라는 1위 원문 근거 안의 설명으로 생성됐습니다. 스마트키 답변은 구체적인 교체 절차 대신 질문을 소개하는 문장이 되었고, 12V 답변도 절차를 설명하지 못했습니다. 두 답변 모두 서버가 사용자에게 노출하기 전에 차단했습니다.

실문서 수락률은 이번 작은 탐색 세트에서 `1/3 (0.3333)`입니다. 합성 24/24 결과와 달리 현재 1.5B 후보는 실제 긴 설명서를 안정적으로 요약하지 못하므로 기본 생성 답변으로 승인하지 않습니다. 검색 원문은 정상 제공하고, 화면에서는 원문 근거를 접어서 열람할 수 있게 유지합니다. 다음 후보 평가는 더 큰 지시 모델 또는 추출형 요약 방식과 같은 질문 세트를 비교해야 합니다.

## 해석과 미완료 범위

- 현재 결과는 제조사 원문을 복제하지 않은 작은 합성 문장 8개에 대한 기능·성능 측정입니다.
- 24회가 모두 같은 결과였어도 실제 차량 설명서의 긴 문맥, 여러 출처, 표, 페이지 오류와 다양한 한국어 질문을 대표하지 않습니다.
- 넥쏘·ELECTRIFIED GV70 실제 문서 탐색 E2E는 수행했지만 3문항뿐이고 1문항만 통과했으므로 품질 승인이 아닙니다.
- 합성 데이터 첫 호출 약 17초, 실제 문서 탐색 첫 호출 약 35초는 사용자 요청 경로에서 그대로 기다리기에 길어 서버 시작 후 명시적인 예열이나 비동기 준비 상태가 필요합니다.
- 더 큰 실제 문서 평가와 대체 모델 비교가 끝날 때까지 기본값은 `source-list`이며, 파일럿 모델을 자동 다운로드하거나 GitHub Pages에서 실행하지 않습니다.
