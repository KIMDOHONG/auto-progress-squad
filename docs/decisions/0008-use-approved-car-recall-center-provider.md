# ADR-0008: 승인된 자동차리콜센터 공급자만 사용

## 상태

승인

## 배경

Issue #19는 활성 차량 또는 명시한 차량의 리콜을 공식 출처와 조회 시각을 포함해 표시해야 합니다. 자동차리콜센터는 한국교통안전공단 자동차안전연구원이 운영하며, [공식 API 안내](https://www.car.go.kr/rs/cnter/intrcn.do?tabNum=6)에서 조회 기간에 해당하는 리콜정보와 VIN 리콜정보 API를 제공한다고 설명합니다.

다만 이 API는 베타서비스이며 사전 협의를 거쳐 제공 여부를 결정합니다. 공개 페이지에는 이 프로젝트가 바로 호출해도 되는 인증 정보와 확정 응답 계약이 없습니다. 따라서 공개 HTML을 자동 수집하거나 미공개 URL·필드를 추측해서는 안 됩니다.

## 결정

- 공식 공급자 이름은 `자동차리콜센터`, 기준 URL은 `https://www.car.go.kr/home/main.do`로 고정합니다.
- 공급자는 `RecallProvider` 계약을 구현하고 애플리케이션 시작 시 명시적으로 주입합니다.
- 공급자가 없으면 기존처럼 `recall_source_not_configured` 503으로 실패 폐쇄합니다.
- 공급자가 있으면 저장된 차량의 제조사·차명·연식·프로젝트 코드를 조회 범위로 전달합니다.
- 제조사 법인명·유니코드·공백·구두점·대소문자만 정규화하고 `제조사|차명|연식|세대|프로젝트 코드`가 모두 같은 결과만 반환합니다. 임의 차명 별칭이나 인접 연식·세대 대체는 허용하지 않습니다.
- 0건은 `no_results` 정상 응답으로 반환하고 공급자 장애는 `recall_source_unavailable` 503으로 구분합니다.
- 응답과 개별 결과의 링크는 HTTPS 자동차리콜센터 도메인만 허용합니다.
- VIN 조회는 차량번호·VIN 저장 및 외부 전송 동의 흐름이 별도로 구현되기 전에는 사용하지 않습니다.

## 결과

승인된 API 사양과 자격 정보가 준비되면 현재 계약 뒤에 HTTP 어댑터와 캐시를 추가할 수 있습니다. 현재 PR은 공급자 경계와 상태 구분만 구현하며 실제 자동차리콜센터 호출, 정확 매칭과 VIN 조회를 완료로 간주하지 않습니다.

공식 안내 확인일은 2026-09-01입니다.
