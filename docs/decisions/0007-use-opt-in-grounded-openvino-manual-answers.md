# ADR-0007: 선택형 OpenVINO 근거 답변과 서버 인용 검증 사용

- 상태: Accepted
- 결정일: 2026-08-29
- 보완일: 2026-09-07
- 관련 이슈: #18

## 배경

매뉴얼 검색 API는 현재 차량의 승인 문서에서 원문 청크와 위치를 반환하지만, 사용자가 읽기 쉬운 생성형 답변은 제공하지 않았다. 생성 모델의 JSON 형식 준수만으로는 사실성이나 올바른 인용을 보장할 수 없으며, 모델 파일과 실제 차량 매뉴얼 품질을 확인하지 않은 상태에서 기본 응답을 생성형으로 바꾸면 근거 밖 절차나 수치가 노출될 수 있다.

## 결정

- 기본 `source-list` 모드는 기존처럼 검색 성공 안내와 원문 출처만 반환한다.
- `APS_MANUAL_ANSWER_MODE=openvino`를 명시한 검증 환경에서만 OpenVINO GenAI 생성 답변을 활성화한다.
- 모델 가중치와 특정 모델 선택은 저장소에 포함하지 않는다. 운영자가 검토한 로컬 모델 경로를 `APS_MANUAL_GENERATION_MODEL_PATH`로 지정한다.
- 질문과 검색 1위 근거는 신뢰하지 않는 JSON 데이터로 프롬프트에 넣고, 현재 1.5B CPU 파일럿은 답변을 1개의 짧은 `text`·`citations` claim으로 제한한다. 나머지 검색 결과는 생성 입력에 섞지 않고 사용자가 확인할 공식 원문 후보로 그대로 반환한다.
- 모델에는 구조화 출력 JSON 스키마를 적용하지만, 모델 출력의 인용 표시는 신뢰하지 않는다. 서버가 인용 번호 범위·중복, 근거에 없는 숫자와 최소 어휘 중첩을 검증한 뒤 `[n]` 표기를 직접 렌더링한다.
- 검색 결과가 없으면 모델을 호출하지 않는다. 생성·로드 오류와 검증 실패는 기존 출처 목록 응답으로 자동 대체하지 않고 각각 `503 manual_answer_generation_unavailable`, `503 manual_answer_validation_failed`로 실패 폐쇄한다.
- API 응답은 실제 답변 경로를 `answer_engine`으로, 검증에 사용된 출처 번호를 `citations`로 공개한다.

## 결과와 제한

- 기본 설치와 기존 API 동작에는 생성 의존성이 추가되지 않는다.
- 구조화 출력과 서버 검증으로 인용 위조, 근거에 없는 숫자와 크게 벗어난 문장을 차단할 수 있다.
- 어휘 중첩 검사는 의미적 함의를 증명하는 장치가 아니며, 지원되는 claim이 항상 완전하거나 자연스럽다는 보장도 하지 않는다.
- 실제 모델 파일을 사용한 CPU 품질·지연·메모리 E2E와 승인된 실제 매뉴얼 평가가 완료되기 전에는 이 모드를 운영 기본값으로 전환하지 않는다.

## 파일럿 측정 메모

2026-08-30에 Apache-2.0의 `OpenVINO/Qwen2.5-1.5B-Instruct-int4-ov` 고정 리비전을 합성 한국어 근거 8문항에 각 3회 연결했다. 24회 생성·인용·필수 정보 검증은 모두 통과했고 i5-1135G7 CPU에서 첫 호출 약 17.37초, 웜 p50 약 2.75초, 최고 RSS 약 2.10GB였다. 모델 선택 근거와 재현 조건은 `models/manual-generation-candidates.md`에 기록한다.

이 측정으로 선택형 공급자와 검증 경계가 실제 OpenVINO 모델에서도 동작함은 확인했지만, 합성 문장은 승인된 제조사 원문을 대표하지 않았다. 따라서 이 시점에는 파일럿 후보만 정하고 운영 기본값과 실제 문서 E2E 미완료 상태를 유지했다.

## 2026-09-07 보완

넥쏘 2021과 ELECTRIFIED GV70 2027 실제 문서의 대표 질문 3개를 추가 측정한 결과, 1.5B 후보는 1개 답변만 생성·근거 검증을 통과했습니다. 긴 검색 결과 5개를 모두 넣는 방식은 첫 호출 지연과 형식 실패가 커서, 선택 모드의 생성 입력을 검색 1위 발췌문 1개와 최대 1,200자로 제한하고 출력도 최대 1개 claim·160 생성 토큰으로 줄였습니다. “설명서에 따르면”처럼 질문에 직접 답하지 않는 메타 문장도 서버 검증에서 차단합니다.

이 보완은 실패 답변의 노출을 줄이기 위한 파일럿 경계이며 모델 품질 승인이나 기본 활성화를 뜻하지 않습니다. 화면은 검증된 답변을 `AI 설명`으로 표시하고, 모든 검색 출처는 접을 수 있는 `공식 원문 근거`로 별도 제공됩니다. 실제 문서 수락률이 1/3이므로 운영 기본값은 계속 `source-list`입니다.
