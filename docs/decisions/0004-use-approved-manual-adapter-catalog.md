# ADR-0004: 승인된 제조사 매뉴얼 카탈로그 사용

- 상태: Accepted
- 결정일: 2026-08-28
- 관련 이슈: #17, #18

## 배경

쉐보레 공식 취급설명서 페이지는 세대명이 포함된 모델별 경로와 장별 PDF 링크를 제공한다. KGM 공식 페이지는 현재·이전 모델, 설명서 발행 시점과 장별 PDF 목록을 제공한다. 두 제조사 모두 같은 차명 아래 여러 세대 또는 발행 시점이 존재하므로 최신 문서나 비슷한 연식을 자동 선택하면 잘못된 차량 설명서를 연결할 수 있다.

KGM 홈페이지 이용약관은 회사와 관계사의 사전 승낙 없는 정보 복제·유통·상업적 이용을 제한한다. 따라서 공개 화면이나 내부 API를 주기적으로 수집하는 기능을 기본 동작으로 추가하지 않는다.

## 결정

- 쉐보레·KGM 어댑터는 서버 관리자가 검토해 `adapter-manifest.json`에 승인한 매핑만 사용한다.
- 매핑 식별자는 제조사, 공식 차명, 차량 연식과 세대 문자열의 조합이다.
- 같은 차명·연식에 여러 세대가 있으면 세대 입력 없이는 조회하지 않는다.
- 일치하는 연식이 없으면 최신 또는 인접 연식 문서로 넓히지 않는다.
- 각 매핑은 공식 모델 페이지, 확인일과 한 개 이상의 장별 PDF 제목·URL을 포함한다.
- 쉐보레 PDF는 `www.chevrolet.co.kr`, KGM PDF는 `www.kg-mobility.com`의 HTTPS URL만 허용한다.
- 매뉴얼 PDF와 제조사 API 응답은 저장소에 커밋하지 않는다.
- 카탈로그가 없거나 잘못된 경우 `503`, 정확한 매핑이 없으면 `404`, 세대 선택이 필요하면 `409`로 실패 폐쇄한다.

## 결과

- 운영자는 이용 조건과 차량 일치 여부를 검토한 항목만 단계적으로 활성화할 수 있다.
- 원문 링크와 장 순서를 유지하면서 다른 차량 문서 혼입을 막을 수 있다.
- 제조사 페이지 구조 변경이 서비스 코드 변경 없이 manifest 검토·교체로 분리된다.
- 자동 수집을 활성화하려면 제조사의 별도 사용 허가와 응답 계약 검증이 선행되어야 한다.
