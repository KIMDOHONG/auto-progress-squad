# ADR-0006: 운영자가 승인한 장별 매뉴얼 파일을 한 문서로 수집

- 상태: Accepted
- 결정일: 2026-08-29
- 관련 이슈: #18

## 배경

현대·기아·제네시스는 한 차량의 설명서를 단일 파일로 준비할 수 있지만, 쉐보레와 KGM의 공식 페이지는 한 설명서를 여러 장별 PDF로 제공한다. 기존 수집 manifest는 문서마다 로컬 파일 하나만 허용했으므로 승인 카탈로그에 정확한 장별 공식 URL이 있어도 검색 인덱스를 만들 수 없었다.

제조사 사이트의 파일을 서비스가 자동으로 내려받거나 저장소에 복제하는 것은 이용 조건과 운영 정책 검토가 선행되어야 한다. 또한 여러 장을 합치면서 하나의 대표 URL만 저장하면 검색 결과가 실제 근거 장으로 이동하지 못한다.

## 결정

- 기존 단일 `file` 형식과 새 `chapters` 형식 중 정확히 하나만 manifest 문서에 허용한다.
- `chapters`의 각 항목은 장 제목, 제조사 공식 HTTPS 원문 URL, 운영자가 승인 디렉터리에 준비한 로컬 PDF/TXT 경로를 포함한다.
- 쉐보레·KGM 승인 카탈로그를 프로필에 정확히 연결하면 결정적인 문서 키로 `pending` 작업을 만든다. 인접 연식이나 유사 차명으로 넓히지 않는다.
- 작업자는 모든 장 파일을 하나의 논리 문서로 추출하고, 장 제목과 공식 URL을 각 청크에 저장한다. 페이지 번호는 각 원본 파일 안에서 1부터 시작한다.
- 묶음 해시는 장 순서, 장 제목, 공식 URL과 파일 바이트를 모두 포함한다. 어느 하나라도 바뀌면 전체 논리 문서와 청크를 한 트랜잭션에서 교체한다.
- 단일 파일 또는 장별 파일 묶음의 총 읽기 크기는 100MB를 넘을 수 없고, 모든 로컬 경로는 승인 디렉터리 내부여야 한다.
- 제조사 자동 다운로드, PDF 재배포와 이용 허가 판단은 이번 결정에 포함하지 않는다.

## 결과

- 장별로 나뉜 설명서를 실제 검색 평가에 사용할 수 있고, 결과의 장 제목·페이지·공식 URL이 같은 원본을 가리킨다.
- 기존 단일 파일 manifest는 계속 동작한다. 해시 구성에 출처 메타데이터가 추가되므로 업그레이드 후 기존 문서는 최초 한 번 다시 추출될 수 있다.
- 운영자가 원문 파일을 합법적으로 확보하고 승인 디렉터리에 배치해야 하며, 파일이 없으면 작업은 실패 상태를 명시한다.
- 자동 다운로드를 추가하려면 제조사 허가와 응답 계약 검증을 별도 결정으로 남겨야 한다.
