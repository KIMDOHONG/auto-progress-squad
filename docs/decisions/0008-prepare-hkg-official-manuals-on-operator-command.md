# ADR-0008: 현대·기아·제네시스 공식 설명서는 운영자 명령으로 준비한다

## 상태

채택

## 배경

현대·기아·제네시스 공식 취급설명서 사이트는 공통 차종·연식 API와 차량별 설명서 메타데이터 API를 제공한다. 차량에 따라 전체 PDF가 제공되기도 하고 웹 도움말만 제공되기도 하므로 PDF만 받는 준비 절차로는 EV6 같은 차량을 검색 인덱스에 넣을 수 없다.

화요일 마감 범위에서는 세 제조사의 정확한 차량 문서 검색을 우선하고 다른 제조사 확장은 후속 작업으로 남긴다.

## 결정

- 등록 프로필에서 검증된 `manual_site_id`, 프로젝트 코드, 연식을 사용하며 `hmc`, `kia`, `genesis`만 처리한다.
- 운영자가 `app.official_manual_prepare` 명령과 `--confirm-official-source`를 직접 실행한 경우에만 원문을 로컬에 준비한다. 웹 요청이나 일반 사용자 질문은 다운로드를 시작하지 않는다.
- 공식 메타데이터가 전체 PDF를 제공하면 PDF를 저장하고, PDF가 없고 웹 도움말이 있으면 동일 공식 호스트와 해당 설명서 경로 아래의 목차 본문만 UTF-8 TXT로 저장한다.
- 리디렉션 후 최종 URL까지 제조사별 HTTPS 호스트와 허용 경로를 다시 검증한다.
- 대표 설명서 페이지와 웹 도움말의 각 본문 URL을 manifest에 보존한다.
- 파일은 `APS_MANUAL_SOURCE_DIR`에만 두고 Git에 포함하지 않는다.
- 기존 `제조사:프로젝트코드:연식` 문서 키, 해시 재사용, 차량별 검색 차단 규칙을 그대로 사용한다.

## 결과

차종별 코드를 별도로 추가하지 않고도 공식 차종 API로 등록 가능한 현대·기아·제네시스 차량에 같은 준비 파이프라인을 적용할 수 있다. PDF가 없는 차량도 장별 공식 출처를 유지한 채 검색할 수 있다. 원문 이용 조건 확인과 다운로드는 운영자의 명시적 실행 경계에 남는다.

다른 제조사, 자동 주기 수집, 제조사 원문 재배포, 실제 문서 기반 검색·생성 품질 평가는 이 결정에 포함하지 않는다.
