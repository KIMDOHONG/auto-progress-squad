# 0001. 사용자 차량 프로필 기반 통합 자동차 AI 코파일럿

- 날짜: 2026-08-24
- 상태: 승인
- 참여자: 자동진행단

## 배경

자동차 관련 챗봇 후보를 유지보수, 차량 설명, 실생활 세 계열로 검토했다. 여러 기능을 각각 분리된 챗봇으로 만드는 대신, 사용자가 차량을 최대 3대까지 등록하고 현재 차량을 공통 문맥으로 사용하는 하나의 웹 애플리케이션이 사용자 가치와 발표 흐름에 더 적합하다고 판단했다.

## 결정

프로젝트 주제를 **사용자 차량 프로필 기반 통합 자동차 AI 코파일럿**으로 정한다.

핵심 기능:

1. 차량 최대 3대 등록과 현재 차량 선택
2. 개인화 대시보드와 우측 고정 챗봇
3. 경고등·증상 기반 안전 대응
4. 차량 매뉴얼 RAG와 리콜정보
5. 전기차 경로·충전 계획
6. 중고차 자료 기반 위험 분석
7. 답변의 사실·계산·AI 추정 및 출처 구분

## 현재 제외

- OBD-II 연동: 별도 장비 필요
- 타이어 사진 분석: 학습 데이터와 실차 검증 필요
- 자동차 소음 분류: 환경별 오디오 데이터와 별도 모델 평가 필요

제외 기능은 현재 UI에 미완성 기능으로 노출하지 않으며, 구현·검증 여력이 확보된 경우에만 향후 ADR과 Issue를 통해 추가한다.

## 근거

- 세 명이 병렬로 웹, RAG·AI, 외부 API·분석 영역을 담당할 수 있다.
- 공통 차량 프로필을 사용해 여러 기능을 하나의 사용자 경험으로 연결할 수 있다.
- RAG, API, 계산 모듈, OpenVINO 적용 근거를 함께 제시할 수 있다.
- 학습 데이터가 부족한 이미지·오디오 기능을 제외해 완성도와 검증 가능성을 높인다.

## 결과와 위험

- 외부 API와 매물 페이지에 의존하므로 캐시·직접 입력·파일 업로드 대체 경로가 필요하다.
- 자동차 안전과 중고차 사고 분석은 확정 진단이 아니라 근거·가능성·불확실성으로 표현한다.
- 남은 일정에 맞춰 필수 기능과 확장 기능의 우선순위를 Issue에서 관리한다.
