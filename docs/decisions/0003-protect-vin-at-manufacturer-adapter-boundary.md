# ADR-0003: 제조사 매뉴얼 어댑터와 VIN 보호 경계

- 상태: Accepted
- 결정일: 2026-08-28
- 관련 이슈: #17

## 배경

BMW Driver's Guide는 17자리 VIN으로 정확한 차량 설명서를 식별한다. 공식 웹 애플리케이션은 VIN을 공개키로 암호화한 뒤 BMW API에 요청하지만, 해당 API는 이 프로젝트의 브라우저 origin에 CORS 접근을 허용하지 않는다. BMW Korea 법적 고지는 사이트의 이미지·그래픽 등 저작물을 다른 웹사이트에 복사하거나 게시할 권리를 부여하지 않는다.

쉐보레와 KGM은 모델·연식별 여러 문서 또는 장별 PDF를 제공하므로 BMW와 같은 식별 절차를 그대로 사용할 수 없다. 공통 URL을 추측하는 대신 제조사별 식별 전략을 같은 어댑터 계약 뒤에 둬야 한다.

## 결정

- 모든 제조사 매뉴얼 연결은 `ManufacturerManualAdapter` 계약을 구현한다.
- 공개 API `GET /api/v1/manual-adapters`는 식별 방식, 연동 위치, 현재 지원 상태, 식별값 저장 여부와 이미지 정책을 반환한다.
- BMW 라이브 조회는 브라우저가 아닌 서버 전용으로 제한한다.
- BMW 외부 연동 사용 허가가 확인되기 전에는 `bmw_driver_guide_permission_required`로 실패 폐쇄한다.
- 원문 VIN은 요청 처리 메모리에서만 사용하고 URL, 접근 로그, 애플리케이션 로그, SQLite, 작업 큐, 캐시에 저장하지 않는다. 진단 표시가 필요하면 앞 3자리와 뒤 4자리만 남겨 마스킹한다.
- 향후 BMW 요청을 활성화할 때에는 매 요청마다 공식 키를 확인해 서버에서 암호화하고, 암호화 토큰도 저장하지 않는다.
- BMW 공식 차량 이미지는 복사·재호스팅·영구 URL 저장을 하지 않는다. 별도 사용 허가가 확인되기 전까지 이미지 정책은 `none`이다.
- 쉐보레와 KGM은 현재 공식 시작 페이지만 제공하고 정확한 모델·연식·세대 매핑이 구현될 때까지 `planned`로 표시한다.

## 결과

- 프런트엔드는 실제 조회가 가능한 제조사와 공식 링크만 제공하는 제조사를 구분할 수 있다.
- 사용 허가나 정확한 식별이 없는 상태를 성공으로 표현하지 않는다.
- BMW VIN과 이미지 토큰이 차량 프로필 또는 매뉴얼 인덱스에 섞이지 않는다.
- 라이브 BMW 조회, 동적 차량명·연식 정규화, 임시 이미지 전달은 사용 허가와 실제 응답 계약을 검증한 후 별도 변경으로 구현한다.

## 확인한 공식 경계
