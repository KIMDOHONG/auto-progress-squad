# ADR-0002: FastAPI 백엔드 기반 선택

- 상태: Accepted
- 결정일: 2026-08-26
- 관련 이슈: #3

## 배경

프런트엔드 MVP 뒤에 차량 프로필, 매뉴얼 검색, 리콜 조회와 공통 오류 응답을 연결할 HTTP API가 필요하다. 팀이 짧은 기간 안에 자동 API 문서, 입력 검증과 Python 기반 AI 파이프라인 연결을 함께 다뤄야 한다.

## 결정

- Python 3.12와 FastAPI를 백엔드 기반으로 사용한다.
- API 경로는 `/api/v1` 아래에 둔다.
- Pydantic 모델을 프런트엔드와의 계약으로 사용한다.
- 초기 로컬 저장소는 Python 표준 `sqlite3`와 SQLite를 사용한다.
- 의존성과 개발 환경은 `uv`와 `uv.lock`으로 재현한다.
- 브라우저 접근은 명시한 개발 주소와 GitHub Pages origin만 CORS로 허용한다.

## 결과

- `/docs`에서 OpenAPI 계약을 확인할 수 있다.
- 차량 프로필 저장 구조와 매뉴얼·리콜 API 경계를 먼저 고정할 수 있다.
- 매뉴얼 RAG와 리콜 데이터가 연결되기 전에는 `503`과 구조화 오류를 반환한다.
- SQLite는 MVP용이며 동시 사용자·운영 배포 요구가 커지면 별도 데이터베이스 ADR이 필요하다.

## 이번 결정에 포함하지 않는 것

- 임베딩 모델과 벡터 저장소
- OpenVINO 적용 방식
- 매뉴얼 PDF 수집·분할 규칙
- 리콜 OpenAPI 공급자
- 운영 서버 배포 방식
