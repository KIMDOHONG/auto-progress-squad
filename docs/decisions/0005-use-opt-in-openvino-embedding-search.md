# ADR-0005: 선택형 OpenVINO 임베딩 검색 사용

- 상태: Accepted
- 결정일: 2026-08-29
- 관련 이슈: #18

## 배경

현재 키워드 검색은 합성 한국어 8문항에서 `Hit@3 0.75`, `MRR 0.75`였고, 동의어나 자연스러운 표현이 원문과 다르면 관련 청크를 놓쳤다. 같은 질문 세트에서 `multilingual-e5-small` OpenVINO FP32는 두 지표가 모두 `1.0`이었지만, 모델 캐시는 약 465.4MB이고 첫 로드에 약 8.7초가 필요했다. 합성 8문항만으로 실제 취급설명서 품질과 운영 임곗값을 확정할 수는 없다.

## 결정

- 기존 `keyword` 검색을 서버 기본값으로 유지한다.
- `APS_MANUAL_SEARCH_MODE=embedding`을 명시한 검증 환경에서만 OpenVINO 임베딩 검색을 활성화한다.
- 기본 모델은 고정 리비전의 `intfloat/multilingual-e5-small`이며 질문에 `query: `, 문서에 `passage: ` 접두어를 사용한다.
- 모델은 첫 검색에서 지연 로드하고 문서 벡터는 문서 내용 지문별로 메모리에 최대 4개 보관한다.
- 현재 차량의 정확한 `document_key`에 속한 청크만 벡터화·검색한다.
- 모델 의존성·다운로드·로드·추론 실패를 키워드 검색으로 대체하지 않고 `503 manual_embedding_unavailable`로 반환한다.
- 파일럿 최소 유사도는 `0.82`로 두되 환경 변수로 조정할 수 있게 하며, 실제 문서 평가 전에는 운영 확정값으로 간주하지 않는다.
- 응답은 검색 엔진 식별자와 원문 출처만 추가하며 생성형 답변은 이 결정에 포함하지 않는다.
- 모델 가중치는 저장소에 커밋하지 않는다.

## 결과

- 기존 설치와 테스트는 OpenVINO 선택 의존성 없이 계속 실행된다.
- 검증 환경은 같은 API 계약에서 의미 검색을 재현하고 실제 사용 엔진을 확인할 수 있다.
- 모델 오류가 성공한 키워드 결과처럼 숨겨지지 않는다.
- 프로세스 재시작 시 모델과 벡터를 다시 준비해야 하며, 영속 벡터 인덱스와 콜드 스타트 최적화는 후속 검토가 필요하다.
