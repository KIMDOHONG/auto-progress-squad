# ADR-0011: 공식 원문 핵심 발췌를 기본 매뉴얼 답변으로 사용

- 상태: Accepted
- 결정일: 2026-09-07
- 관련 이슈: #18

## 배경

기본 `source-list` 화면은 공식 원문을 안전하게 보존하지만 사용자가 긴 검색 결과를 직접 읽어야 했다. 선택형 OpenVINO 1.5B 모델은 합성 근거에서는 동작했으나 넥쏘·ELECTRIFIED GV70 실제 문서 대표 질문의 생성·근거 검증을 1/3만 통과해 운영 기본값으로 사용할 수 없었다.

## 결정

- 기본 `APS_MANUAL_ANSWER_MODE`를 `extractive`로 지정한다.
- 검색 1위의 현재 차량 공식 원문에서 질문 토큰과 직접 겹치는 완결 문장 또는 번호 단계를 최대 3~4개 선택한다.
- PDF 줄바꿈, 페이지·장 표식과 이미지 코드만 정리하고 문장을 새로 생성하거나 바꾸어 쓰지 않는다.
- 답변에는 서버가 `[1]`을 붙이고 `answer_engine=extractive-grounded-v1`, `citations=[1]`을 반환한다.
- 화면에는 `공식 원문 핵심 안내`와 `질문 관련 문장 발췌`라고 표시해 `AI 설명`과 구분한다.
- 원문 검색 결과는 모두 접을 수 있는 `공식 원문 근거`로 유지한다. 완결 문장을 안전하게 선택하지 못하면 `source-list-v1` 안내만 반환한다.
- 검증 환경의 `openvino` 생성 모드와 명시적 `source-list` 모드는 그대로 유지한다.

## 검증 결과

2026-09-07 로컬 공식 문서 인덱스에서 넥쏘 2021의 권장 타이어 공기압·수소 충전구 닫기·스마트키 배터리 교체와 ELECTRIFIED GV70 2027의 충전 커넥터 잠금·저압 타이어 경고·12 V 배터리 방전·부스트 모드 질문을 비교했다. 제목·이미지 코드가 답변에 섞이지 않고, 번호 단계와 공식 페이지 인용이 유지되는 것을 확인했다. API 단위·통합 테스트는 원문 밖 문장을 만들지 않는 경계와 추출 실패 시 출처 목록 안내를 검증한다.

## 결과와 제한

- 별도 모델 다운로드·메모리·생성 지연 없이 긴 원문 목록 앞에 읽기 쉬운 핵심 문장을 제공한다.
- 의미를 요약하거나 여러 페이지의 정보를 종합하지 않으므로, 검색 1위 문서 조각이 불완전하면 답변도 불완전할 수 있다.
- 안전 절차와 세부 조건은 반드시 함께 제공되는 공식 원문 링크·페이지에서 확인해야 한다.
- 향후 더 큰 OpenVINO 모델은 이 기본 경계를 대체하지 않고 동일한 실제 문서 평가를 통과한 뒤 별도 선택지로 비교한다.
