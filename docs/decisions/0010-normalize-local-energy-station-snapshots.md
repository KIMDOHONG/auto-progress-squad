# ADR-0010: 에너지 충전·주유소 데이터를 로컬 정규 스냅샷으로 연결

## 상태

승인

## 배경

Issue #5의 경로 계산은 NAVER Maps 실제 좌표 경로까지 제공하지만, 전기차 충전소·수소충전소·주유소 공급자는 서로 다른 필드와 갱신 주기를 사용합니다. 공급자별 응답을 화면과 경로 계산에 직접 결합하면 API 교체가 어렵고, 키가 없는 로컬 개발에서는 후보 탐색을 재현할 수 없습니다.

## 결정

- 서버 내부 공통 항목은 에너지 종류, 식별자, 이름, 주소, 좌표, 이용 상태, 상태 조회시각, 전기 출력, 수소 압력, 취급 유종과 원문 URL로 정규화합니다.
- `APS_STATION_CATALOG_PATH`가 가리키는 로컬 JSON 스냅샷을 선택형 공급자로 사용합니다. 저장소에는 대용량 데이터나 API 키를 넣지 않습니다.
- 선택된 실제 경로 좌표와 충전·주유소의 최단 직선거리를 계산해 설정 반경 안의 후보만 반환합니다. 이 값은 실제 도로 우회거리나 우회시간이 아닙니다.
- 지정연료 정보가 명시된 주유소는 일치 항목만 남기고, 취급 정보 자체가 없으면 `unknown`으로 보존해 사용자에게 미확인 경고를 표시합니다.
- 공급자 미설정, 정상 0건, 공급자 장애를 각각 `503 station_source_not_configured`, `200 no_results`, `503 station_source_unavailable`로 구분합니다.
- 모든 응답은 데이터 조회시각과 "대기시간 미포함" 경고를 포함합니다. 개별 상태 조회시각이 없으면 현재 이용 가능 여부를 직접 확인하도록 추가 경고합니다.

## 로컬 스냅샷 형식

최상위에는 `source_name`, `source_url`, `retrieved_at`, `stations`가 필요합니다. 각 항목은 `station_id`, `name`, `address`, `longitude`, `latitude`, `energy_kind`를 필수로 가지며, 공급자가 제공하는 경우에만 `status`, `status_observed_at`, `power_kw`, `pressure_bar`, `fuel_grades`, `source_url`을 추가합니다.

`energy_kind`는 `electric`, `hydrogen`, `fuel` 중 하나이고 `status`는 `available`, `busy`, `unavailable`, `unknown` 중 하나입니다. 실제 공급자 원문을 이 형식으로 변환하는 수집 어댑터는 별도 구현하며, 출처와 이용 조건을 확인하지 않은 데이터를 공식 정보처럼 저장하지 않습니다.

## 결과와 제한

- 공급자별 어댑터와 UI가 같은 경로 후보 계약을 재사용할 수 있습니다.
- 로컬 스냅샷으로 반경 필터·정렬·오류 처리를 반복 검증할 수 있습니다.
- 현재 단계는 실제 전기·수소·주유소 API 호출, 도로 우회시간, 대기시간, 충전곡선 계산을 구현하지 않습니다.
