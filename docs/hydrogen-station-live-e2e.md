# 수소충전소 실제 계정키 E2E 기록

- 검증일: 2026-09-08
- 범위: 한국석유관리원 수소충전소 운영정보·실시간정보 결합 어댑터
- 실행 환경: 로컬 FastAPI `8000`, Vite `5173`, SQLite 동기화
- 비밀정보: 서비스키와 원 API 요청 URL·응답 본문은 기록하지 않음

## 검증 경로

- 출발지: 부산광역시 동구 중앙대로 176 대한통운빌딩
- 목적지: 강원특별자치도 인제군 기린면 상하답로 130
- NAVER Maps 선택 경로: 실시간 빠른 길, 약 455 km
- 수소충전소 탐색 반경: 경로선 기준 5 km

## 확인 결과

`POST /api/v1/planner/stations`가 `matched`를 반환했고 화면에 5곳이 표시되었습니다. 각 후보에서 다음 필드가 실제 운영정보와 실시간정보를 같은 관리번호로 결합한 값으로 확인되었습니다.

- 충전소 이름·도로명주소·좌표
- 경로선 직선거리·경로 진행률
- 이용 가능 상태
- 700 bar 또는 800 bar 충전기 규격
- 대기 차량 수
- 튜브트레일러 압력
- 상태 확인 시각과 전체 자료 조회시각

검증 시각이 야간이어서 표시된 5곳은 모두 `이용 불가`였습니다. 이는 운영마감 또는 실시간 운영/POS 상태를 보수적으로 통합하는 현재 정책과 일치하며, `대기 0대`를 이용 가능으로 잘못 해석하지 않았습니다.

프런트엔드는 자료 출처를 한국석유관리원 수소충전소 운영·실시간정보로 표시하고 공공데이터포털 원문 링크를 제공했습니다. 예상 대기시간과 실제 충전 가능량은 API가 제공하지 않으므로 계산 결과에서 미포함 항목으로 유지했습니다. 브라우저 콘솔에는 애플리케이션 오류가 없었습니다.

## 판정

두 활용신청의 승인 정보가 공급자 서버에 반영된 뒤 실제 계정키 E2E가 통과했습니다. 이전 `resultCode=01`은 코드 회귀가 아니라 승인 정보 반영 전 상태로 판단합니다. 수소충전소 어댑터는 현재 MVP의 실제 데이터 경로로 사용할 수 있으며, 다음 외부 공급자 작업은 오피넷 주유소 API입니다.
