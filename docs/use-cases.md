# 유스케이스

## UC-01 차량 등록과 선택

- 사용자 목표: 소유 차량을 최대 3대까지 등록하고 현재 차량을 선택한다.
- 입력: 제조사, 모델, 연식, 트림, 동력원, 차량 별명
- 정상 흐름:
  1. 차량 정보를 입력한다.
  2. 시스템이 알려진 제원과 매뉴얼 연결 가능 여부를 확인한다.
  3. 차량 카드를 생성한다.
  4. 사용자가 현재 차량을 선택한다.
  5. 대시보드와 챗봇이 선택 차량 문맥을 사용한다.
- 예외:
  - 네 번째 차량 등록 시 기존 차량 삭제 또는 수정 안내
  - 미지원 트림은 직접 제원 입력 또는 기본 모델 선택
  - VIN은 선택사항이며 화면과 로그에서 마스킹

## UC-02 경고등·증상 안전 상담

- 사용자 목표: 경고등과 증상에 따른 우선 행동을 확인한다.
- 입력: 경고등 종류, 점등/점멸, 차량 떨림·출력·온도 등
- 출력: 위험 등급, 추가 질문, 운행 여부, 점검 권장순서
- 예외:
  - 정보 부족 시 확정 답변을 하지 않고 추가 질문
  - 즉시 위험 가능성이 있으면 운행 중단과 전문점 점검 우선
  - 정비 확정 진단으로 표현하지 않음

## UC-03 매뉴얼 질문과 리콜 확인

- 사용자 목표: 현재 차량의 기능과 안전정보를 빠르게 찾는다.
- 정상 흐름:
  1. 현재 차량을 선택한다.
  2. 자연어로 질문하거나 리콜 카드를 누른다.
  3. 매뉴얼 검색 또는 리콜 API를 호출한다.
  4. 답변, 문서 위치·원문, 조회시각을 표시한다.
- 예외:
  - 지원 문서 없음
  - 리콜 API 장애 또는 차종 매칭 실패
  - 유사 차종 정보를 현재 차량 정보처럼 표시하지 않음

## UC-04 동력원별 운행 에너지 계획

- 사용자 목표: 활성 차량에 맞는 전기·수소 충전소 또는 지정연료 주유소를 경로에서 찾는다.
- 공통 입력: 활성 차량, 출발지, 목적지
- 전기차 입력: 현재 SoC, 최근 전비, 도착 최소 SoC
- 수소전기차 입력: 현재 주행가능거리
- 내연기관 입력: 현재 주행가능거리, 차량 지정연료(일반·고급·초고급 휘발유, 일반·하이세탄 경유)
- 정상 흐름:
  1. 활성 차량의 동력원을 확인한다.
  2. 길찾기 API로 기본 경로와 시간을 조회한다.
  3. 전기차이면 소비전력과 경로 충전소를 계산한다.
  4. 수소전기차이면 경로 주변 수소충전소의 운영·충전 가능 상태와 우회시간을 확인한다.
  5. 내연기관이면 지정연료 취급점과 현재 주행가능거리 내 후보를 검색한다.
  6. 주행, 우회, 충전 또는 주유시간을 포함한 후보를 비교한다.
- 출력: 동력원별 충전·주유 후보, 우회시간, 도착 예상 상태, 계산 조건과 데이터 조회시각
- 예외:
  - API 장애 시 경로 거리 직접 입력
  - 특수연료 취급 여부를 확인할 수 없으면 확인되지 않은 주유소로 명시
  - 충전기 실시간 상태가 오래됐으면 경고
  - 수소충전소 운영·충전 가능 상태를 확인할 수 없으면 미확인으로 명시
  - 대기시간과 실제 충전속도는 보장하지 않음

## UC-05 중고차 구매 위험 분석

- 사용자 목표: 매물과 점검자료에서 주요 위험과 추가 확인 항목을 찾는다.
- 입력:
  - 매물 링크
  - 성능상태점검기록부 이미지/PDF
  - 보험이력 자료 또는 부품·공임·도장비
- 정상 흐름:
  1. 공개적으로 접근 가능한 매물 정보를 읽는다.
  2. 실패하면 파일 업로드 또는 직접 입력을 요청한다.
  3. 구조 손상, 외판 교환, 침수·전손, 반복사고 신호를 분석한다.
  4. 위험 등급, 가능한 사고 유형, 근거, 신뢰도를 제공한다.
  5. 실차 점검 항목을 안내한다.
- 예외:
  - 보험금만으로 사고부위를 확정하지 않음
  - 개인정보는 저장·출력 시 마스킹
  - 자료 불일치 시 판단 보류

## UC-06 상시 챗봇과 기능 이동

- 사용자 목표: 어느 화면에서도 현재 차량과 화면 결과를 문맥으로 대화한다.
- 동작:
  - 우측 챗봇을 항상 표시
  - 메뉴 선택을 우선 라우팅 신호로 사용
  - 챗봇이 해당 기능 화면을 열거나 필요한 입력 위젯을 표시
  - 모든 답변에 사실·계산·AI 추정을 구분
