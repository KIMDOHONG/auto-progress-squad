## 역할 배분 원칙

- 세 명 모두 핵심 흐름을 설명하고 실행할 수 있어야 합니다.
- 특정 사람만 접근 가능한 계정·장비·데이터를 만들지 않습니다.
- 각 담당 영역에는 최소 한 명의 교차 검토자를 둡니다.
- AI가 생성한 결과는 담당자가 실행·검증한 뒤 완료 처리합니다.

## GitHub 규칙

- Issue: 목적, 작업 내용, 완료 조건을 기록
- Branch: `feature/<issue-number>-short-name`, `docs/<issue-number>-short-name`
- PR: 관련 Issue 연결, 테스트 결과, 미검증 범위 기록
- Commit: 하나의 논리적 변경을 간결한 메시지로 기록
