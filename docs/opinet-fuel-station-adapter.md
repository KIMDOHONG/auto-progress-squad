# 오피넷 주유소 어댑터 구현 기록

## 범위

2026-09-09 기준으로 한국석유공사 오피넷의 `반경 내 주유소`와 `주유소 상세정보` API를 경로 주변 주유소 후보 조회에 연결했다. 인증키는 `APS_OPINET_SERVICE_KEY` 프로세스 환경변수로만 전달하며 저장소, 브라우저 응답, 로그에 기록하지 않는다.

## 처리 흐름

1. NAVER 경로 좌표에서 최대 24개 표본점을 고른다.
2. WGS84 좌표를 오피넷의 KATEC 좌표로 변환한다.
3. 각 표본점에서 공식 최대 반경인 5 km 안의 주유소를 거리순으로 조회한다.
4. 중복 주유소 ID를 제거하고 경로선과의 직선거리로 후보를 다시 정렬한다.
5. 최대 15개 후보의 상세 API를 호출해 도로명 주소, 제품 가격, 가격 기준시각을 결합한다.
6. 최종 화면에는 사용자가 선택한 탐색 반경과 후보 개수 제한을 적용한다.

반경·상세 응답은 기본 15분 동안 메모리에 캐시한다. 장거리 경로에서도 오피넷 일반 API 호출 한도를 과도하게 소모하지 않도록 표본점과 상세 요청 수에 상한을 두었다.

## 지정연료 처리 경계

오피넷이 공개한 제품코드 B027, B034, D047을 각각 일반휘발유, 고급휘발유, 자동차경유로 연결한다. 이 세 종류는 조회 제품이 일치할 때만 `취급 확인`으로 표시한다. 초고급휘발유와 하이세탄경유는 별도 공개 제품코드가 없으므로 주변 후보를 참고용으로 찾되 취급 여부와 가격을 확인된 사실처럼 표시하지 않는다.

오피넷 반경·상세 API는 현재 영업 여부를 제공하지 않는다. 따라서 주유소 상태는 `상태 미확인`으로 유지하고, 화면에 가격과 가격 기준시각을 별도로 표시한다. 표시 거리는 실제 진입 우회거리나 소요시간이 아니라 경로선과의 직선거리다.

## 검증 결과

- FastAPI 테스트: 160 passed
- React 테스트: 107 passed
- 프런트엔드 프로덕션 빌드: 성공
- KATEC 변환과 공식 예시 좌표, 반경·상세 응답 결합, 동일 주유소 중복 제거, 고급휘발유 가격·시각 표시를 자동 테스트로 확인
- 초고급휘발유의 취급·가격을 추정하지 않는 실패 폐쇄 동작을 자동 테스트로 확인

실제 발급키를 이용한 화면 종단간 확인은 새 실행 스크립트에서 오피넷 키를 입력한 뒤 BMW M3 고급휘발유 경로로 수행한다. 이 확인 전에는 실제 계정 연결 완료로 기록하지 않는다.
