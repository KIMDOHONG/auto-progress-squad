# 매뉴얼 검색 품질 평가 기준

- 관련 이슈: #18
- 기준 측정일: 2026-09-08
- 검색 구현: `keyword-intent-v3`
- 데이터: `tests/fixtures/manual-search-evaluation.v1.json`

## 목적

임베딩·벡터 검색을 도입하기 전에 현재 키워드 검색의 재현 가능한 기준값을 남깁니다. 후보 검색 방식은 같은 질문과 청크에서 측정해 이 기준과 비교합니다.

평가 데이터는 제조사 설명서 원문이 아닌 한국어 합성 문장입니다. 저장소와 CI에서 반복 실행하기 위한 작은 기능 테스트이며, 실제 차량 설명서 전체의 품질을 대표하지 않습니다.

## 실행

```powershell
cd src/api
$env:PYTHONUTF8 = "1"
uv run --locked python -m app.manual_search_evaluation `
  ../../tests/fixtures/manual-search-evaluation.v1.json
```

평가기는 각 질문의 정답 페이지가 상위 3개 결과에 포함되는 비율인 `Hit@3`와, 첫 정답 순위의 역수를 평균한 `MRR`을 JSON으로 출력합니다.

## 실제 공식 문서 기준선

운영자가 준비한 로컬 공식 문서 인덱스가 있을 때는 원문을 저장소에 복제하지 않고 질문과 정답 위치만 기록한 `tests/fixtures/manual-live-evaluation.hkg.v1.json`으로 평가합니다. PDF는 정답 페이지를 사용하고, 각 장의 페이지 번호가 다시 1부터 시작하는 웹 설명서는 공식 장 URL 또는 장 제목을 사용합니다.

```powershell
cd src/api
uv run python -m app.manual_live_evaluation `
  ../../tests/fixtures/manual-live-evaluation.hkg.v1.json
```

2026-09-08에 준비한 넥쏘 2021 공식 PDF(451쪽, 580청크), ELECTRIFIED GV70 2027 공식 PDF(594쪽, 704청크), EV6 2026 공식 웹 설명서(상위 목차와 하위 상세 항목 532장, 752청크)를 키워드 검색으로 평가한 결과는 다음과 같습니다.

- 질문: 넥쏘 5개, ELECTRIFIED GV70 7개, EV6 7개, 총 19개
- `Hit@3`: `1.0000`
- `MRR`: `1.0000`
- 제조사 출처 격리: 통과

키워드 v1의 최초 측정값은 `Hit@3 0.6667`, `MRR 0.6667`이었습니다. 키워드 v2에서 공백 정규화와 제한된 동의어 처리를 추가했습니다. v3는 화면에서 확인된 실패 질문을 고정 평가에 추가하고 열기/닫기, 실제 출발/예약 출발, 충전 출력 단위, 점프 시동, 잠금 설정, 공기압 위치, 급속 충전 절차, 배터리 용량, 침수 대응 의도를 구분합니다. 차량 충전기의 정격만 있는 문장에서 차량 최대 충전 출력을 추정하지 않고, 근거가 없으면 원문과 차량 제원을 확인하도록 안내합니다. 기아 실제 질문에는 급속 충전, 커넥터 분리, 예약 충전, 12 V 점프스타트, 공기압 라벨, 배터리 용량, 침수 대응을 포함했습니다. 웹 설명서는 상위 목차뿐 아니라 본문 안의 하위 상세 항목을 공식 도메인과 경로 안에서 재귀 수집하고, 삭제된 선택 하위 링크만 건너뜁니다. 질문 수가 작으므로 `1.0000`은 전체 설명서 질문 품질을 뜻하지 않으며, 실제 사용자 질문 세트를 계속 확장해야 합니다.

평가기는 차량의 준비 상태가 `ready`이고 문서 키가 정확히 일치할 때만 실행됩니다. 각 검색 결과의 URL 호스트가 해당 현대·기아·제네시스 공식 도메인인지도 함께 검사하므로 다른 차량이나 제조사 문서가 섞이면 `source_isolation_pass`가 실패합니다.

## 현재 기준값

| 항목 | 결과 |
| --- | ---: |
| 질문 수 | 8 |
| 청크 수 | 8 |
| 검색 결과 제한 | 3 |
| Hit@3 | 1.0000 |
| MRR | 1.0000 |

8개 질문 모두 정답 청크를 1순위로 찾았습니다. v2에서 실패했던 다음 두 동의어 질문도 v3의 제한된 동의어 정규화로 회귀 테스트에 포함됩니다.

- `집에서 천천히 충전하려면 어디에 꽂아?` → `완속 충전 커넥터` 청크
- `아이들이 뒷문을 안에서 못 열게 하는 기능` → `어린이 보호 잠금` 청크

이 결과는 작은 합성 세트에서의 기능 회귀 방지 값이며 실제 설명서 전체 품질을 대표하지 않습니다.

## 다음 비교 조건

임베딩·벡터 검색 후보는 다음 조건을 동일하게 적용해 별도 결과로 기록합니다.

1. 같은 데이터와 `Hit@3`, `MRR` 계산을 사용합니다.
2. 현재 성공한 8개 질문의 정답 순위를 악화시키지 않는지 확인합니다.
3. 실제 문서 19개 질문의 순위와 답변 가능 여부를 함께 확인합니다.
4. 모델명·버전·라이선스·실행 장치와 평균 검색 시간을 함께 기록합니다.
5. 실제 서비스 적용 판단 전에는 이용이 승인된 더 큰 문서 집합과 질문 세트로 다시 측정합니다.

## OpenVINO 후보 측정

실제 로컬 CPU 측정 결과와 모델 선택 근거는 [매뉴얼 임베딩 후보 비교](../models/manual-embedding-candidates.md)에 기록했습니다. 현재 8문항에서는 `multilingual-e5-small`이 모두 1순위로 검색됐지만, 이 결과만으로 실제 설명서 전체 품질을 확정하지 않습니다.

서버 검색은 기본 `keyword` 모드를 유지하며, `APS_MANUAL_SEARCH_MODE=embedding` 또는 `hybrid`를 지정한 검증 환경에서만 OpenVINO 후보를 사용합니다. 하이브리드는 의도 키워드 결과를 우선하면서 의미 검색의 동의어 보완을 합칩니다. 모델 오류를 키워드 성공으로 숨기지 않으며, 최소 점수와 실제 사용 엔진을 응답에서 확인할 수 있습니다.
