# 문제 정의

## 1. 프로젝트명

**사용자 차량 프로필 기반 통합 자동차 AI 코파일럿**

## 2. 해결할 문제

차량 소유자는 경고등, 사용설명서, 리콜, 전기차 충전 계획, 수소충전소 운영 정보, 중고차 사고이력처럼 서로 다른 정보를 여러 사이트와 문서에서 따로 찾아야 합니다. 전문 용어가 많고 차량별 정보가 달라 검색 결과를 자신의 차량에 바로 적용하기도 어렵습니다.

본 프로젝트는 사용자의 차량 정보를 공통 문맥으로 사용하는 하나의 웹 서비스에서 관련 기능을 제공하고, 사실과 AI 추정을 구분해 다음 행동을 이해하기 쉽게 안내합니다.

## 3. 대상 사용자

- 자신의 차량 기능과 안전정보를 빠르게 확인하려는 운전자
- 전기차·수소전기차 장거리 운행과 충전을 계획하는 사용자
- 중고차 매물과 점검자료를 비교하려는 구매 예정자

## 4. 핵심 목표

사용자가 차량을 최대 3대까지 등록한 뒤 현재 차량을 선택하면, 웹 대시보드와 상시 표시 챗봇이 해당 차량을 기준으로 다음 기능을 제공합니다.

1. 경고등·증상 기반 안전 대응
2. 사용설명서 RAG 검색과 출처 제시
3. 차종별 리콜·안전정보 조회
4. 전기차 충전 계획과 수소전기차 충전소 경로 확인
5. 중고차 점검자료·보험이력 기반 위험 분석

## 5. 입력과 출력

| 기능 | 입력 | 출력 |
| --- | --- | --- |
| 차량 프로필 | 제조사, 모델, 연식, 트림, 동력원 등 | 최대 3대의 차량 프로필과 현재 차량 |
| 유지보수 | 경고등 종류, 증상, 운행 상태 | 위험도, 추가 질문, 권장 행동, 근거 |
| 매뉴얼·리콜 | 현재 차량, 자연어 질문 | 매뉴얼 근거 답변, 리콜 알림과 원문 |
| EV 계획 | 현재 SoC, 전비, 출발지, 목적지 | 예상 소비전력, 도착 SoC, 추천 충전소, 시간 범위 |
| 수소차 계획 | 현재 주행가능거리, 출발지, 목적지 | 경로 주변 수소충전소, 운영 상태, 우회 정보 |
| 중고차 분석 | 매물 링크, 점검표·보험이력 파일 또는 수치 | 위험 등급, 가능한 사고 유형, 확인 필요 항목 |

## 6. 성공 기준

| 항목 | 완료 기준 |
| --- | --- |
| 개인화 | 차량 3대를 등록하고 현재 차량을 모든 기능에서 공통 사용 |
| 매뉴얼 RAG | 평가 질문에 근거 문서 위치와 함께 답변 |
| 리콜 | 선택 차량의 조회 결과, 출처, 조회시각 표시 |
| 유지보수 | 대표 경고등·증상 시나리오에서 위험도와 다음 행동 제공 |
| EV 계획 | 경로·충전소·차량 제원을 사용한 계산 과정과 범위 표시 |
| 수소차 계획 | 경로 주변 수소충전소의 상태·조회시각·우회 정보 표시 |
| 중고차 | 구조 손상과 단순 외판 가능성을 구분하고 근거·불확실성 표시 |
| 안전성 | 외부 사실, 계산 결과, AI 추정을 화면에서 구분 |
| 재현성 | 설치·실행·테스트 명령과 자동 점검 제공 |

정량 기준값은 데이터와 평가 세트가 확정된 뒤 Issue에서 추가합니다.

## 7. 이번 프로젝트 범위

### 포함

- 반응형 웹 대시보드와 우측 고정 챗봇
- 차량 프로필 최대 3대와 현재 차량 선택
- 메뉴 기반 기능 라우팅
- 경고등·증상 대화형 안전 안내
- 매뉴얼 RAG 및 리콜 API
- 전기차 기본 경로·충전 계획
- 수소전기차 기본 충전소 경로 확인
- 중고차 자료 업로드·입력 기반 위험 분석
- 출처·시각·불확실성 표시
- OpenVINO 적용 및 추론 성능 비교

### 제외

- OBD-II 장비 연동
- 타이어 사진 분류·세그멘테이션
- 자동차 소음 분류
- 보험이력 유료 결제 자동화
- 중고차 사고부위 확정 진단
- 실시간 충전 대기시간 보장
- 실제 내비게이션 턴바이턴 안내
